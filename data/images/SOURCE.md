# Image source

Photos from the `dataset/` folder of
[nicolasmetallo/car-damage-detector](https://github.com/nicolasmetallo/car-damage-detector) (MIT License).
Renamed for readability; original file names are in `manifest.json` → `source_file`.
`img_unusable_dark_01.jpg` is a blurred/darkened copy made here to test the unusable-image path.

Labels in `manifest.json` were assigned by eye. Left vs right side is not reliably visible in
close-up photos, so side images accept either `left_side` or `right_side`.
